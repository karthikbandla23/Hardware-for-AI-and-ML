## How to Reproduce the Co-Simulation

**Dependencies:** Icarus Verilog 12.0 (`apt install iverilog`)

```bash
cd project/m3
iverilog -g2012 \
  -o tb_top_sim \
  ../m2/rtl/compute_core.sv \
  ../m2/rtl/interface.sv \
  rtl/top.sv \
  tb/tb_top.sv
vvp tb_top_sim
```

Expected final output: `tb_top: PASS`

## How to Reproduce the Synthesis Run

**Dependencies:** OpenLane 2.3.10 via Nix

```bash
# Install Nix (single-user)
curl -L https://nixos.org/nix/install | sh -s -- --no-daemon
. ~/.nix-profile/etc/profile.d/nix.sh

# Install OpenLane 2
nix --extra-experimental-features "nix-command flakes" profile install github:efabless/openlane2

# Run synthesis
openlane project/m3/synth/config.json
```

OpenLane 2 version: 2.3.10  
PDK: sky130A (downloaded automatically by OpenLane via Volare)  
Run tag: RUN_2026-05-24_19-44-32
